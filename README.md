Vite + React + TypeScript project initialised with Tailwind CSS and shadcn/ui component library.

## Development

Run the app locally:

```bash
npm run dev
```

Open the local URL printed by Vite (typically `http://localhost:5173`).

## Build

Create a production build:

```bash
npm run build
```

Preview the production bundle locally:

```bash
npm run preview
```

## Lint

Run ESLint:

```bash
npm run lint
```

## Tech Stack

- Vite
- React 19 + TypeScript
- Tailwind CSS v4
- shadcn/ui primitives
